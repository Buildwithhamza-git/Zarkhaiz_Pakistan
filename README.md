# 🌾 Zarkhaiz Pakistan

An AI-powered agriculture platform connecting farmers and agricultural suppliers across Pakistan. The platform enables farmers to buy agricultural products, detect crop diseases using AI, receive smart recommendations, and access modern farming solutions from a single marketplace.

---

## 📌 Project Overview

Zarkhaiz Pakistan is a MERN Stack based web application designed to modernize Pakistan's agricultural ecosystem by connecting farmers, suppliers, and agricultural experts through a digital marketplace enhanced with Artificial Intelligence.

The platform aims to simplify the process of purchasing farming products, improve crop health through AI-powered disease detection, and provide intelligent recommendations for fertilizers, pesticides, and farming practices.

## ⚙ Installation

### Clone Repository

```bash
git clone <repository-url>
```

### Frontend

```bash
cd client

npm install

npm run dev
```

### Backend

```bash
cd server

npm install

npm run dev
```

---

## 🌐 Environment Variables

Create a `.env` file inside the **server** directory.

```
PORT=5000

MONGO_URI=your_mongodb_connection_string

JWT_SECRET=your_secret_key
```
